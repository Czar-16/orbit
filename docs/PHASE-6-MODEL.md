# Phase 6 model and data boundary

The user's explicit approval-wait override through Phase 6 authorizes this model. Existing local architecture is retained.

Workspace owns immutable ApplicationDraft revisions, unique by workspace/job/revision, with restrictive composite workspace-scoped relations to Job, JobRevision, ProfileVersion, PreferenceVersion and ResumeVersion. Each save/regeneration/discard appends a revision; a workspace lock and expected revision reject stale tabs. Draft JSON contains validated letter, answer provenance, exact original project/resume lines and selected indexes, match snapshot, unresolved fields and provider. Discard appends a tombstone rather than erasing history. Saved defaults are snapshot preference versions if none exists. No Application or submission model/status is added in this phase.

ResumeVersion gains roleCategory and isDefault metadata; one active default per workspace is enforced with a partial unique index. Immutable bytes remain private and existing draft links keep the selected version. Extraction is transient, bounded, local, and requires explicit review in the existing profile form; no extracted facts are automatically verified. Draft emphasis stores originals and ordered indexes only. Verified projects are included only when the exact bullet occurs in the selected extracted resume, otherwise listed as unavailable for resume emphasis.

Workspace owns OutboundDataLog rows with feature/provider/model, sent field names, UTC timestamp and attempted/succeeded/failed result. Never log raw profile content, prompts, secrets or responses. Log before requests, including local-model boundary calls. AI defaults off; hosted requires explicit environment opt-in to spending and an explicit UI choice. AI may select/reorder allowlisted verified sentence indexes and bullet indexes only; arbitrary model prose is never persisted. No job-description instructions enter the AI prompt. Analysis and answers stay deterministic; the abstraction provides safe supplementary selection for explanation/letter/questions. Fixed official OpenAI endpoint or loopback Ollama only; no redirects, bounded time/response, Zod validation, no automatic retries. These optional interfaces will not be advertised as connected without a real test.

Implementation detail: PreferenceVersion gains origin=user/defaults so an automatic defaults snapshot is never misrepresented as a user preference save. ApplicationDraft uses a three-column workspace/job/job-revision foreign key, and a SQL append-only trigger. Outbound result constraints and one-active-default index are enforced in migration 202610120008.
